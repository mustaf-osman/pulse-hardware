# Nimo 提醒助手产品与硬件方案 V1

## 一句话定位

Nimo 提醒助手是一套面向客户、老师、门店和个人办公场景的桌面 AI 提醒服务：用户说一句或发一条微信，它帮你记；到时间，电脑、微信、桌面硬件屏幕和灯光一起提醒。

## 第一阶段目标

第一阶段先把软件端提醒系统做出来，不急着做完整固件。桌面端负责创建提醒、管理待办、展示提醒、配置微信和硬件设备；硬件端先预留接口和显示协议。

## 核心功能

- 电脑端创建提醒
- 微信文字创建提醒
- 后续支持硬件语音创建提醒
- 到点电脑端弹窗提醒
- 到点微信提醒
- 到点硬件屏幕显示文字、时间、表情
- 到点硬件灯光闪烁
- 支持完成和稍后提醒
- 支持今日待办列表
- 支持隐私模式
- 支持客户、老师、门店、项目等不同对象的提醒分类

## 硬件方向

当前硬件按用户提供的旗舰版套件预留：

- 亚克力底板
- 电容触摸屏
- ESP32-S3 摄像头模块
- 传感器拓展包
- 小车底盘
- 32G TF 卡
- Type-C 数据线
- 7.4V 2000mAh 锂电池与充电器
- 可与 STM32 控制器通讯
- 可与 ESP32 控制器通讯

## 硬件能力分层

### MVP 必需

- 屏幕显示提醒文字、时间、表情
- 灯光提醒普通、紧急、稍后状态
- 设备心跳
- 拉取待提醒任务
- 上报完成和稍后

### 第二阶段

- 触摸屏确认完成和稍后
- 摄像头只用于设备交互或扩展实验，不默认做人脸识别
- 传感器用于桌面存在感、距离、环境状态等轻交互

### 第三阶段

- 小车底盘移动
- 更多传感器联动
- 与 STM32/ESP32 外设模块协同

## 设备 API 预留

- `POST /nimo/devices/register`
- `POST /nimo/devices/heartbeat`
- `GET /nimo/devices/:id/reminders/pending`
- `POST /nimo/reminders/:id/complete`
- `POST /nimo/reminders/:id/snooze`
- `POST /nimo/devices/:id/display`
- `POST /nimo/devices/:id/light`

## 提醒通道

- `desktop`
- `wechat`
- `robot_screen`
- `robot_light`
- `robot_voice`

## 隐私边界

敏感提醒不在硬件上直接朗读具体内容，只显示“你有一个重要提醒”。摄像头能力先作为硬件预留，不在第一版启用人脸识别或持续监控。
